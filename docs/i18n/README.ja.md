# Code Doctor

[English](../../README.md) · [한국어](README.ko.md) · [简体中文](README.zh-CN.md)

エージェントが変更したコードを理解し、短い指示で作業の方向を調整するためのツールです。Claude CodeとCodexがすべての変更を動作や判断ごとのブロックにまとめ、重要度と理解に必要な順序で説明します。普段の会話やdiffで読み、複数の意見をまとめて返します。次のブロックを見るためのモデル呼び出しは不要です。

初期プレビューです。新しいモデルサービスやAPIキーは必要ありません。skillやMCPを接続するだけで、専用のネイティブパネル・自動ハイライト・自動送信が追加されるわけではありません。[検証範囲と制限](../validation.md)を確認してください。

## インストール

Node.js 22以上とGitが必要です。macOS/Linuxで一度インストールします。

```sh
git clone https://github.com/PresentJay/code-doctor.git
cd code-doctor
npm ci --ignore-scripts --no-fund
node bin/code-doctor.mjs install --host both
```

インストーラーは既存設定を保ちながら、ユーザーのフックとskillを登録し、Codexにはユーザー単位のMCP接続も追加します。一方だけなら`--host codex`または`--host claude`を指定してください。ソースと依存関係を維持してください。編集済みの既存設定は上書きしません。

新しいセッションを開始してください。Codexでは最初に一度、`/hooks`でフックを確認して信頼する必要があります。有効化後は普段どおり開発を依頼すると、Gitリポジトリで自動的に案内します。毎回Code Doctorを呼ぶ必要はありません。Conductorなどでは、エージェントのユーザーフックを読み込む場合に限り動作します。Windowsの自動インストールは未対応です。

会話がGitリポジトリの外で始まっても、作業対象のファイルから実際のリポジトリを確認し、そのリポジトリとセッションの有効・無効設定に従います。最終応答の前に、同じターン内でコードの説明に抜けがないか確認します。フックの成功は説明の提供を保証せず、終了フックによる追加実行は行いません。

「このリポジトリではCode Doctorをオフにして」「この会話ではオフにして」「すべてオフにして」と依頼し、同じ範囲で再びオンにできます。「この作業だけ省略」は現在の作業だけに適用します。直接操作する場合は`node bin/code-doctor.mjs disable --repo PATH`または`enable --repo PATH`を使います。全体は`--scope global`、状態確認は`status --repo PATH`です。より広い範囲の無効設定が優先され、設定はユーザーフォルダーに保存されます。 リポジトリや会話で無効にしても、明示的な再有効化に必要な制御情報は残します。無効な対象のコード説明は作成せず、別の作業リポジトリの設定は個別に確認します。全体で無効にするとフックの情報も送信しません。

プロジェクト別のMCP接続を希望する場合は[任意の設定手順](../../README.md#optional-project-mcp-connection)に従ってください。生成ファイルにはマシン固有の絶対パスが入り、Gitの変更一覧に現れる場合があります。共有済みの設定全体を隠さないでください。CLIの`capture`は変更一覧だけを作成します。説明付きのguideを読む前に、現在のエージェントが`plan`を準備します。

## 使い方

普段どおり開発を依頼してください。例：「カートが空の場合の合計計算を修正して」。作業中は重要な範囲の変更を知らせ、完了時には説明と実際のコードをまとめて提示します。

エージェントは元の依頼・作業の種類・関連要件を確認し、全体説明、読む順序、実際のコードと全変更一覧を一度に用意します。実際に利用できるネイティブ画面を使い、使えなければ全ブロックを一つの応答に表示します。複数の行コメントをまとめて送るか、ブロック名を指定して一括修正を依頼してください。

Web画面は希望した場合だけ開きます。英語・韓国語・日本語・簡体字中国語を選択できます。言語を切り替えても、コード・エージェントの説明・意見の原文・入力中の下書きは変わりません。説明の言語は会話で指定します。サーバー診断とプロトコルの項目名は英語です。

抜粋はコードの一部です。別のファイルや変更前のコードなど、表示されていない範囲も明示し、原文を確認します。表示行数はレビュー完了率ではありません。意見は正確なコードの版に結び付きます。保存・コピー・閲覧は、実行・デプロイ・マージの承認ではありません。
