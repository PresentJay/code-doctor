# Code Doctor

[English](../../README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

에이전트가 만든 코드를 이해하고 짧은 지시로 방향을 바꾸도록 돕습니다. Claude Code와 Codex가 변경 전체를 동작별 블록으로 묶어 중요도와 이해 순서에 따라 설명합니다. 기존 대화·diff에서 읽고 여러 의견을 한 번에 전달합니다. 블록을 넘기려고 모델을 다시 부를 필요가 없습니다.

초기 시험판입니다. 새 모델 서비스나 API 키는 필요 없습니다. 스킬이나 MCP 연결만으로 전용 네이티브 패널·자동 하이라이트·자동 메시지 전송이 생기지는 않습니다. [확인한 범위와 한계](../validation.md)를 참고하세요.

## 설치

Node.js 22 이상과 Git이 필요합니다. macOS/Linux에서 한 번 설치합니다.

```sh
git clone https://github.com/PresentJay/code-doctor.git
cd code-doctor
npm ci --ignore-scripts --no-fund
node bin/code-doctor.mjs install --host both
```

설치 명령은 사용자 훅과 스킬을 등록하고 기존 설정을 보존합니다. 한 에이전트만 쓰면 `--host codex` 또는 `--host claude`를 지정하세요. 설치 폴더와 의존성을 유지하세요. 수정된 기존 설치는 자동으로 덮어쓰지 않습니다.

새 세션을 시작하세요. Codex는 최초 한 번 `/hooks`에서 훅 신뢰 승인이 필요합니다. 활성화 후에는 평소처럼 개발을 요청하면 Git 저장소에서 자동으로 안내합니다. Code Doctor를 매번 부르거나 레포마다 설치할 필요가 없습니다. Conductor 등은 에이전트의 사용자 훅을 읽는 경우에만 자동 연결됩니다. Windows 자동 설치는 아직 지원하지 않습니다.

대화가 Git 저장소 밖에서 시작해도 실제 작업 파일로 저장소를 확인한 뒤, 해당 저장소와 세션의 켜기·끄기 설정을 따릅니다. 최종 응답 전에 코드 안내가 빠지지 않았는지 같은 작업 턴에서 확인합니다. 훅의 성공 표시가 안내 전달을 보장하지는 않으며, 종료 훅으로 에이전트를 다시 실행하지 않습니다.

“이 레포에서는 Code Doctor 꺼줘”, “이 대화에서는 꺼줘”, “전체에서 꺼줘”로 중단하고 같은 범위에서 다시 켤 수 있습니다. “이번 작업만 빼줘”는 현재 작업에만 적용합니다. 직접 제어하려면 `node bin/code-doctor.mjs disable --repo PATH` 또는 `enable --repo PATH`를 사용합니다. 전체 설정은 `--scope global`, 상태 확인은 `status --repo PATH`입니다. 더 넓은 범위의 끄기 설정이 우선합니다. 설정은 사용자 폴더에 저장됩니다. 저장소나 대화에서 꺼도 요청한 범위를 다시 켤 수 있도록 제어 정보는 남깁니다. 끈 대상의 코드 안내는 만들지 않으며, 다른 작업 저장소의 설정은 따로 확인합니다. 전체에서 끄면 훅 정보도 보내지 않습니다.

프로젝트별 MCP 연결을 원하면 [선택 설치](../../README.md#optional-project-mcp-connection)를 따르세요. 생성되는 설정에는 기계별 절대 경로가 들어가고 Git 변경에 나타날 수 있습니다. 기존 공유 설정을 통째로 숨기지 마세요. CLI의 `capture`는 변경 목록만 만들며, 설명이 담긴 가이드는 현재 에이전트가 `plan`을 준비한 뒤 읽습니다.

## 사용

평소처럼 개발을 요청하세요. 예: “장바구니가 비었을 때 합계 계산을 고쳐줘.” 작업 중 중요한 범위 변경을 알리고, 결과에서는 설명과 실제 코드를 한 번에 보여줍니다.

에이전트가 원래 요청·작업 종류·관련 요구를 확인한 뒤 총평, 읽을 순서, 실제 코드와 전체 목록을 한 번 준비합니다. 실제 지원되는 네이티브 화면을 쓰고, 없으면 모든 블록을 한 응답에 보여줍니다. 여러 줄 의견을 모아 보내거나 블록 이름을 지목해 함께 수정하도록 요청하세요.

웹 화면을 원할 때만 그렇게 요청합니다. 영어·한국어·일본어·중국어 간체를 선택할 수 있고, 언어를 바꿔도 코드·에이전트 설명·의견 원문·작성 중인 입력은 바뀌지 않습니다. 설명 언어는 대화에서 정합니다. 서버 진단과 프로토콜 필드는 영어입니다.

발췌는 코드의 일부입니다. 다른 파일·변경 전 코드처럼 발췌 밖에 남은 범위도 설명하고 원본을 확인합니다. 표시한 줄 수가 검토 완료율은 아닙니다. 의견은 정확한 코드 버전에 기록되며 저장·복사·열람은 실행·배포·병합 승인이 아닙니다.
